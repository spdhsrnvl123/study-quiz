# study-quiz

평일 아침 "오늘의 공부" 메일의 객관식 문제를 푸는 화면입니다. 파일은 `index.html` 하나이고 GitHub Pages로 엽니다.

```
메일 맨 끝 보기(A~D)를 누른다
        │  https://spdhsrnvl123.github.io/study-quiz/#s=2B&d=<문제 묶음>
        ▼
이 화면: 그 보기로 바로 채점(정답이에요 / 오답이에요 + 풀이) → 나머지 문제도 여기서 푼다
        │  다 풀면 '결과 보내기'
        ▼
메일을 보내는 비공개 저장소에 GitHub 이슈 "답: <메일 날짜>" → 다음 날 메일 맨 위에서 다시 짚는다
```

- 문제·정답은 주소의 `#` 뒤(`d=`, JSON을 raw deflate로 줄인 base64url)에만 있습니다. `#` 뒤는 서버로 가지 않아서 이 저장소와 사이트에는 남지 않습니다.
- `s=<문제 번호><보기 글자>`가 있으면 메일에서 그 보기를 누른 것으로 보고 바로 채점합니다.
- 푼 답은 그 기기의 localStorage에만 메일 날짜별로 둡니다.
- 문제 묶음을 만드는 쪽은 메일 저장소의 `wiki/_tools/daily_mail.py`(`quiz_data`)입니다. 모양을 바꾸면 두 곳을 같이 고칩니다.
- `fig/<메일 날짜>/`는 Gmail 안에서 채점하는 AMP판 메일의 그림입니다. AMP 메일은 https 주소의 그림만 실을 수 있어서, 메일을 보낼 때 Actions가 deploy key로 올립니다. 이 화면은 그림을 쓰지 않습니다.
